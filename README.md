# Using-Generative-AI-Tools---Boon-or-Bane.
# Generative AI Research Project

This repository is created for the research project "Using Generative AI Tools - Boon or Bane". It is used to organise research documents, data files, analysis scripts, and reports in a clear and collaborative way.

## Repository Structure

- `01_literature_review/`: Journal articles, conference papers, books, and newspaper articles.
- `02_quantitative_analysis/`: Survey questions, survey data, CSV/Excel files, Python scripts, and quantitative analysis reports.
- `03_qualitative_analysis/`: Interview protocols, anonymised interview transcripts, qualitative analysis notes, insights reports, and data visualisations.
- `04_drafts_and_reports/`: Draft research proposals, conference papers, and final reports.
- `05_additional_materials/`: Information sheets, photos, and other media files.
- `06_documentation/`: Data management plan, file naming conventions, and collaboration guidelines.

## File Naming Convention

Files should be named clearly and consistently so that team members can quickly understand their content. A recommended structure is:

`YYYYMMDD_ProjectName_FileDescription_Version`

Example:

`20260429_GenerativeAI_SurveyAnalysis_v1.xlsx`

## Collaboration Guidelines

Team members should use meaningful commit messages when uploading or updating files. For example:

- `Add initial folder structure`
- `Add survey questions and analysis script`
- `Update literature review summary`
- `Add anonymised interview insights report`

## Data Security

Sensitive data should not be uploaded to a public GitHub repository. This includes consent forms, identifiable interview transcripts, raw survey responses, participant photos, and any personal information.

Sensitive files should be stored in a secure research drive or institutional data management platform with restricted access. Only anonymised data, scripts, reports, and documentation should be uploaded to this repository.
